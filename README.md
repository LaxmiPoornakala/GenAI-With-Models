# Generative AI Model Evaluation using LlamaIndex

## Overview

This project evaluates and compares multiple Large Language Models (LLMs) across different inference platforms using LlamaIndex.

Models evaluated:
- Llama 3.2 (Ollama)
- GPT-4o Mini (OpenAI)
- DeepSeek-R1 (Replicate)
- Llama-3-70B-Instruct (Replicate)

The project focuses on model integration, prompt execution, embedding generation, and response comparison using a unified LlamaIndex workflow.

## Key Features

- Integrated multiple LLM providers through LlamaIndex
- Executed and compared responses from 4 different GenAI models
- Configured local inference using Ollama
- Evaluated cloud-hosted models through OpenAI and Replicate APIs
- Implemented embedding generation using HuggingFace embeddings
- Explored model performance, latency, and output quality
